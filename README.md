# זמן לנגן 🎵
אפליקציית Windows בעברית לליווי אימון עצמאי, ללא חיבור MIDI, ניתוח אודיו או שירות ענן. כולל מטרונום, מעגל קווינטות ומקליט מיקרופון מקומי.

## העלאה לגיטהאב ויצירת מתקין
1. צרו מאגר והעלו **את תוכן התיקייה**, כולל `.github`, לשורש המאגר, לענף `main`.
2. בלשונית Actions, המתינו להצלחת `Test, build and release`. קובץ ההתקנה זמין גם כ־Artifact.
3. ליצירת Release: צרו תג `v1.1.0` בפקודות למטה או דרך Releases → Draft a new release → Choose a tag → Create new tag → Publish. תהליך הבנייה ייצור Release, או יוסיף את המתקין ל־Release שכבר פרסמתם.
4. Settings → Pages → Source: **GitHub Actions**. הריצו את `Download website` בלשונית Actions אם נדרש. כתובת המאגר בדף מוחלפת אוטומטית בזמן הפרסום.
5. להרצה מקומית של `index.html`, החליפו `OWNER/REPOSITORY` בשם המאגר שלכם. אין צורך בשינוי ידני לצורך Pages.

```sh
git add .
git commit -m "Add Zman Lenagen"
git push origin main
git tag v1.1.0
git push origin v1.1.0
```
בעדכון הבא השתמשו בתג חדש, למשל `v1.1.1`. אין צורך בשרת או בסודות נוספים. נדרש מאגר עם Actions ו־Pages פעילים; מומלץ מאגר ציבורי להורדה ציבורית.

## פיתוח
.NET SDK 10, Windows 10 2004 ומעלה / Windows 11 x64, ו־Inno Setup 6.
```sh
dotnet run --project tests/ZmanLenagen.Tests -c Release
dotnet run --project src/ZmanLenagen.App
dotnet publish src/ZmanLenagen.App -c Release -r win-x64 --self-contained true -o publish
```
לאחר פרסום: `ISCC installer/setup.iss`. המתקין נוצר ב־`dist/ZmanLenagen-Setup.exe`. הפצת ARM64 ו־32 סיביות אינה כלולה בגרסה זו.

## מדידת זמן
- דקות שלמות בלבד לתכנון, 1–1440 לכל שלב.
- תצוגת דקות בעיגול כלפי מעלה; פחות מדקה: `<1` ב־LTR. זמן חריגה מוצג במינוס.
- זמן התרגול נמדד בשעון מונוטוני, בנפרד מזמן הטיימר המתוכנן.
- „סיים שלב” עוצר מדידה לפני המשוב. המתנה בין שלבים אינה נספרת.
- כן = 100%, חצי־חצי = 50%, לא = 0%. הנתונים הגולמיים אינם נמחקים.
- השהיה ידנית, נעילת המחשב ושינה עוצרות מדידה. החזרה דורשת לחיצה על „המשך לנגן”.
- נשמר checkpoint בכל שנייה. אחרי קריסה המעגל נפתח מושהה; לכל היותר השנייה האחרונה עלולה לא להישמר. זמן שהתוכנה הייתה סגורה לא נספר.
- שלב בלי משוב אינו נספר; אפשר להשלים משוב לשלבים ישנים במסך הבית.

## שמירה וגיבוי
SQLite עם WAL, synchronous FULL ועסקאות. הנתונים ב־`%LOCALAPPDATA%\ZmanLenagen` של כל משתמש. גיבוי מסד נתונים ראשון בכל יום שבו התוכנה נפתחת, עד 14 גיבויים. JSON מלא כולל שלבים, מקטעי הזמן, משוב ומעגלים אחרונים; CSV כולל כל השלבים. גיבוי JSON ניתן לייבוא במיזוג לפי מזהה, ללא הכפלת שלבים. הגיבוי אינו מחליף את ההיסטוריה הקיימת ואינו מחדש שלב פעיל.

לשחזור מסד שנפגם: סגרו את התוכנה, שמרו עותק של התיקייה המקורית, העתיקו קובץ תקין מ־`backups` ל־`practice.db`, והסירו מן התיקייה הפעילה את `practice.db-wal` ואת `practice.db-shm` אם קיימים. אפשר גם לייבא JSON בהתקנה עם תיקיית נתונים חדשה. אין למחוק את המקור לפני שמוודאים שחזור.

## התקנה והסרה
מתקין ברמת המחשב עם AppId קבוע, ריצה בהרשאות משתמש רגילות ושדרוג בהתקנה חוזרת. הסרה מוחקת קבצי תוכנה וקיצורי דרך, ושומרת היסטוריה. „ניהול נתונים” מאפשר מחיקה מפורשת של הנתונים והגיבויים בחשבון הנוכחי. כדי להסיר נתונים מכל החשבונות יש לבצע זאת בכל חשבון לפני הסרת התוכנה. רישום התראות הוא לכל משתמש; ההסרה מנקה אותו בחשבון שמריץ את פעולת ההסרה. בחשבונות אחרים מחיקת הנתונים דרך האפליקציה מנקה גם אותו.

## סטטיסטיקות
7/30 ימים כולל היום מול התקופה הקודמת באותו אורך; ימים ללא תרגול מוצגים; גרף 12 חודשי לוח (החודש הנוכחי חלקי); תגיות בחלון 30 יום והיסטוריית 60 שלבים אחרונים. ייצוא כולל את כולם. אימון חוצה חצות מחולק לפי מקטעי הזמן באזור הזמן הנוכחי של המחשב. שינוי אזור הזמן עשוי לשנות שיוך של היסטוריה לימים. מספר סבבים נספר לפי מזהים עם תרגול בחלון הנבחר, לא לפי מספר שלבים. משך בסיכומים עשוי להכיל שבר דקה כדי לא לאבד אימונים קצרים.

## בדיקות
ראו `VALIDATION.md` ו־`MANUAL-TESTS.md`. פעולת CI בונה את קוד Windows ואת המתקין. בדיקות שולחן העבודה וההתראות דורשות Windows אינטראקטיבי ואינן מבוצעות על ידי בדיקות הליבה.

## מגבלות התראות וחתימה
התראות Windows משתמשות ב־CommunityToolkit.WinUI.Notifications. האפליקציה צריכה להיות פתוחה (אפשר ממוזערת). Windows יכול להשתיק התראות במצב „נא לא להפריע”. הזמן ממשיך גם אם ההתראה חסומה. צפצוף תלוי בהגדרות השמע. המתקין אינו חתום; תעודת חתימה אינה כלולה. אין עדכון אוטומטי ואין טלמטריה.

## עזרי נגינה (גרסה 1.1)

פס קבוע בכל המסכים: מטרונום משמאל, מעגל קווינטות במרכז ומקליט מימין. המיקום נשמר גם בממשק RTL. בחלון צר ניתן לגלול בתוך כרטיסי העזרים; המעגל מוצג ב־Viewbox ללא חיתוך תווים.

המטרונום משתמש ב־NAudio 2.2.1 ו־WASAPI משותף. הקליקים נוצרים לפי מספרי דגימות ב־48 kHz, עם מיקום פעימה שברי מחושב מההתחלה: עיגול אינו מצטבר לאורך זמן. טיימר הממשק מציג רק חיווי ואינו מייצר את הקצב. Windows, חומרת השמע ושעון כרטיס הקול מגבילים את הדיוק; אין הבטחה לדיוק מוחלט מול שעון חיצוני. 20–300 BPM, Tap Tempo לפי עד שש הקשות אחרונות, משקלי 2/4, 3/4, 4/4, 5/4, 6/8, 7/8, חלוקה ל־1/2/3/4 ו־3 גווני קליק. ב־6/8 וב־7/8 BPM מתייחס לשמינית; שינויים מתחילים תיבה חדשה.

המעגל מכיל 12 זוגות מז׳ור ומינור מקביל. רק G♭ / F♯ ו־E♭m / D♯m מוצגים בשני שמות. Unicode ♭ ו־♯ ושמות LTR שומרים על מיקום ההיתק מימין לאות. הכפתור המרכזי בוחר באקראי אחד מ־24 הסולמות בהסתברות שווה.

המקליט משתמש במיקרופון ברירת המחדל של Windows. אין הקלטה עד לחיצה על ״הקלט״. נדרשת גישת מיקרופון ליישומי שולחן עבודה בהגדרות הפרטיות של Windows. בזמן הקלטה אין השמעה, כדי להימנע מהקלטת ההשמעה דרך הרמקולים; המטרונום יכול להמשיך ועלול להיקלט דרך הרמקולים.

WAV וקובץ JSON נפרד לכל הקלטה נשמרים ב־`%LOCALAPPDATA%\ZmanLenagen\recordings`. כותרת WAV מתעדכנת פעם בשנייה; סיום מסיים את הכותרת ומעביר קובץ זמני לשמו הקבוע. בפתיחה הבאה נעשה ניסיון לשחזר הקלטה שנקטעה. קריסה, ניתוק מיקרופון או כשל דיסק עשויים לאבד את החלק האחרון; קבצים שלא ניתן לשחזר נשארים בתיקייה עד מועד הניקוי.

תגית ושלב נשמרים בתחילת ההקלטה; משוב והערות מתעדכנים אחרי שמירת המשוב ובכניסה למסך ההקלטות. הקלטה שחוצה שלבים משויכת לשלב שבו התחילה. ״כל ההקלטות״ במסך הבית ובכרטיס המקליט מציג השמעה ישירה, בחירה וייצוא נבחרות/כולן ל־ZIP עם WAV ו־JSON. ייצוא ההיסטוריה הרגיל אינו כולל קובצי שמע.

מחיקה אוטומטית לפי שעת תחילת ההקלטה ב־UTC אחרי שבעה ימים: בפתיחה, בכניסה לארכיון ופעם בשעה כשהתוכנה פתוחה. כשהיא סגורה, הניקוי נדחה לפתיחה הבאה; אין שירות ברקע. ההקלטה הפעילה מוגנת מניקוי. שינה/נעילה מפסיקות ושומרות הקלטה ועוצרות מטרונום והשמעה. התקנה חוזרת שומרת את הנתונים; מחיקת כל הנתונים באפליקציה כוללת גם הקלטות.
