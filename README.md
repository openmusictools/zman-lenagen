# זמן לנגן 🎵
אפליקציית Windows בעברית לליווי אימון עצמאי, ללא MIDI, אודיו או שירות ענן.

## העלאה לגיטהאב ויצירת מתקין
1. צרו מאגר והעלו **את תוכן התיקייה**, כולל `.github`, לשורש המאגר, לענף `main`.
2. בלשונית Actions, המתינו להצלחת `Test, build and release`. קובץ ההתקנה זמין גם כ־Artifact.
3. ליצירת Release: צרו תג `v1.0.0` בפקודות למטה או דרך Releases → Draft a new release → Choose a tag → Create new tag → Publish. תהליך הבנייה ייצור Release, או יוסיף את המתקין ל־Release שכבר פרסמתם.
4. Settings → Pages → Source: **GitHub Actions**. הריצו את `Download website` בלשונית Actions אם נדרש. כתובת המאגר בדף מוחלפת אוטומטית בזמן הפרסום.
5. להרצה מקומית של `index.html`, החליפו `OWNER/REPOSITORY` בשם המאגר שלכם. אין צורך בשינוי ידני לצורך Pages.

```sh
git add .
git commit -m "Add Zman Lenagen"
git push origin main
git tag v1.0.0
git push origin v1.0.0
```
בעדכון הבא השתמשו בתג חדש, למשל `v1.0.1`. אין צורך בשרת או בסודות נוספים. נדרש מאגר עם Actions ו־Pages פעילים; מומלץ מאגר ציבורי להורדה ציבורית.

## פיתוח
.NET SDK 10, Windows 10 2004 ומעלה / Windows 11 x64, ו־Inno Setup 6.
```sh
dotnet run --project tests/ZmanLenagen.Tests -c Release
dotnet run --project src/ZmanLenagen.App
dotnet publish src/ZmanLenagen.App -c Release -r win-x64 --self-contained true -o publish
```
לאחר פרסום: `ISCC installer/setup.iss`. המתקין נוצר ב־`dist/ZmanLenagen-Setup.exe`. הפצת ARM64 ו־32 סיביות אינה כלולה בגרסה זו.

## מדידת זמן
- דקות שלמות בלבד לתכנון, 1–1440 לכל שלב.
- תצוגת דקות בעיגול כלפי מעלה; פחות מדקה: `<1` ב־LTR. זמן חריגה מוצג במינוס.
- זמן התרגול נמדד בשעון מונוטוני, בנפרד מזמן הטיימר המתוכנן.
- „סיים שלב” עוצר מדידה לפני המשוב. המתנה בין שלבים אינה נספרת.
- כן = 100%, חצי־חצי = 50%, לא = 0%. הנתונים הגולמיים אינם נמחקים.
- השהיה ידנית, נעילת המחשב ושינה עוצרות מדידה. החזרה דורשת לחיצה על „המשך לנגן”.
- נשמר checkpoint בכל שנייה. אחרי קריסה המעגל נפתח מושהה; לכל היותר השנייה האחרונה עלולה לא להישמר. זמן שהתוכנה הייתה סגורה לא נספר.
- שלב בלי משוב אינו נספר; אפשר להשלים משוב לשלבים ישנים במסך הבית.

## שמירה וגיבוי
SQLite עם WAL, synchronous FULL ועסקאות. הנתונים ב־`%LOCALAPPDATA%\ZmanLenagen` של כל משתמש. גיבוי מסד נתונים ראשון בכל יום שבו התוכנה נפתחת, עד 14 גיבויים. JSON מלא כולל שלבים, מקטעי הזמן, משוב ומעגלים אחרונים; CSV כולל כל השלבים. גיבוי JSON ניתן לייבוא במיזוג לפי מזהה, ללא הכפלת שלבים. הגיבוי אינו מחליף את ההיסטוריה הקיימת ואינו מחדש שלב פעיל.

לשחזור מסד שנפגם: סגרו את התוכנה, שמרו עותק של התיקייה המקורית, העתיקו קובץ תקין מ־`backups` ל־`practice.db`, והסירו מן התיקייה הפעילה את `practice.db-wal` ואת `practice.db-shm` אם קיימים. אפשר גם לייבא JSON בהתקנה עם תיקיית נתונים חדשה. אין למחוק את המקור לפני שמוודאים שחזור.

## התקנה והסרה
מתקין ברמת המחשב עם AppId קבוע, ריצה בהרשאות משתמש רגילות ושדרוג בהתקנה חוזרת. הסרה מוחקת קבצי תוכנה וקיצורי דרך, ושומרת היסטוריה. „ניהול נתונים” מאפשר מחיקה מפורשת של הנתונים והגיבויים בחשבון הנוכחי. כדי להסיר נתונים מכל החשבונות יש לבצע זאת בכל חשבון לפני הסרת התוכנה. רישום התראות הוא לכל משתמש; ההסרה מנקה אותו בחשבון שמריץ את פעולת ההסרה. בחשבונות אחרים מחיקת הנתונים דרך האפליקציה מנקה גם אותו.

## סטטיסטיקות
7/30 ימים כולל היום מול התקופה הקודמת באותו אורך; ימים ללא תרגול מוצגים; גרף 12 חודשי לוח (החודש הנוכחי חלקי); תגיות בחלון 30 יום והיסטוריית 60 שלבים אחרונים. ייצוא כולל את כולם. אימון חוצה חצות מחולק לפי מקטעי הזמן באזור הזמן הנוכחי של המחשב. שינוי אזור הזמן עשוי לשנות שיוך של היסטוריה לימים. מספר סבבים נספר לפי מזהים עם תרגול בחלון הנבחר, לא לפי מספר שלבים. משך בסיכומים עשוי להכיל שבר דקה כדי לא לאבד אימונים קצרים.
